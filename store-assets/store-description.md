## Full Description (max 10,000 characters — ~1,700 chars below)

Tired of manually switching keyboard layouts every time you switch between apps? **LangKeep** remembers your preferred input language for each application and switches it automatically.

Whether you're typing in English in Visual Studio, German in Teams, French in Chrome, and Bulgarian in Notepad — LangKeep handles it instantly as you switch windows. No hotkeys. No thinking. No interruptions.

### How It Works

1. **Works in the Background** — LangKeep sits quietly in your system tray, monitoring which window is active.
2. **Learns Your Preferences** — Switch to a different keyboard layout while an app is focused, and LangKeep remembers your preference for that app automatically. No manual setup needed.
3. **Switches Automatically** — When you switch between applications, LangKeep restores the keyboard layout you used last time in each app.
4. **Full Control** — Open the Settings window to view, edit, add, or delete language preferences. Export and import your configuration at any time.

### Key Features

🧠 **Automatic Language Restoration** — Switch focus between apps, and LangKeep activates the right keyboard layout immediately.

🎯 **Per-Application Learning** — Change the layout manually while an app is focused, and LangKeep remembers it. No configuration required.

🛠️ **Settings UI** — Clean interface to view, add, edit, delete, export, and import your language preferences.

🖥️ **System Tray Integration** — Minimal, unobtrusive icon with quick-access context menu. Enable/disable auto-switching, toggle startup behavior, or open logs — all from the tray.

🚀 **Start with Windows** — Optionally launch LangKeep automatically when you sign in.

📝 **Structured Logging** — Detailed logs in `%AppData%\LangKeep\logs\` for troubleshooting.

🔒 **Privacy-First** — Everything runs locally on your machine. No data collection, no telemetry, no network requests. LangKeep never sends any information anywhere.

🔓 **Open Source** — MIT-licensed. The full source code is available on GitHub for inspection and contributions.

### Who Is It For?

- **Developers** who switch between IDEs, terminals, and documentation in different languages.
- **Multilingual professionals** working across languages in different tools (email clients, chat apps, office suites).
- **Anyone** who uses multiple keyboard layouts and wants to stop manually switching with Alt+Shift or Win+Space.

### System Requirements

- Windows 10 (version 1809 or later) or Windows 11
- 64-bit (x64) processor
- ~50 MB of storage
